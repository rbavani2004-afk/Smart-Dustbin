# Smart-Dustbin
Smart Dustbin using Arduino and Ultrasonic Sensor
# ♻️ Smart Dustbin

## 📌 About the Project

Smart Dustbin is an automatic waste bin designed to make waste disposal easier and more hygienic.

The system uses an ultrasonic sensor to detect a nearby object and automatically opens the dustbin lid using a servo motor.

---

## 🎯 Objectives

- To create an automatic dustbin
- To reduce physical contact with the dustbin
- To improve hygiene
- To learn sensor-based automation
- To build a simple and low-cost smart system

---

---

## ⚙️ Working Principle

1. The ultrasonic sensor detects a nearby object.
2. Arduino receives the sensor reading.
3. Arduino sends a signal to the servo motor.
4. The servo motor opens the dustbin lid.
5. After a short delay, the lid closes automatically.

### Working Flow

Object Detection  
↓  
Ultrasonic Sensor  
↓  
Arduino  
↓  
Servo Motor  
↓  
Lid Opens  
↓  
Delay  
↓  
Lid Closes
